# 03.1 Variables and Types

> **Level:** Beginner · **Module:** 03 Language Basics · **Status:** ⬜ Not started
> **Estimated time:** 75–90 min

## Why it matters

JavaScript is dynamically typed and has both mutable and immutable bindings. Choosing `let`, `const`, or `var` correctly is the first step to predictable code.
